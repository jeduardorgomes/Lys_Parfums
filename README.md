## 📖 Sobre o projeto

O Lys Parfums é um site de revenda de perfumes construído para funcionar como vitrine digital de um pequeno negócio. A proposta foi criar uma experiência visual minimalista e elegante — inspirada na estética limpa e centrada em produto do site da Apple — priorizando fotos grandes, textos objetivos e um caminho curto até a conversão pelo WhatsApp.

## ✨ Funcionalidades

- 🧴 **Catálogo de produtos** com foto, nome e breve resumo de cada perfume
- 💬 **Contato direto via WhatsApp**, facilitando o fechamento da venda
- 📷 **Link para o Instagram** da loja
- 🏷️ **Seção de promoções**, com destaque para produtos em oferta
- 📱 **Layout responsivo**, adaptado para desktop e mobile

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura semântica das páginas
- **CSS3** — estilização, layout responsivo e identidade visual
- **Vercel** — hospedagem e deploy contínuo

## 🎨 Design

O layout segue uma linguagem visual inspirada no site da Apple: bastante espaço em branco, tipografia limpa, fotos de produto em destaque e poucos elementos de distração — o objetivo é manter o foco do visitante no produto e facilitar a decisão de compra.
